# Coffee Glass

Minecraft Java 1.20.1, Forge 47.4.10, Java 17.

This is intentionally a one-item decorative mod. It contains one standalone 3D item model of coffee in a transparent glass, custom pixel textures and tuned first-/third-person/world display transforms. It adds no recipes, right-click action, effects, blocks or machine logic.

Build with `gradle --no-daemon build`; GitHub Actions also builds the JAR on pushes and pull requests. Output: `build/libs/CoffeMinecraft-Forge-1.20.1-1.0.0.jar`.
