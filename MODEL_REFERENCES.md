# Model references for CoffeMinecraft

The five extra in-game variants in this commit are independently authored Minecraft Java item models with block-shaped geometry and new pixel textures. They are style studies for testing in-game, not redistributed copies of the referenced third-party model files.

- **Minecraft Colourful Cups** by ContinuedOak — visual reference for the three colorful blocky cup options. The source page lists CC BY: https://sketchfab.com/3d-models/minecraft-colourful-cups-19667ec6e76a4e67aaf8a9bd145a4edc
- **Coffee Cup** by ux92 (lucasuriel) — visual reference for the takeaway cup silhouette. The source page lists CC BY-SA: https://sketchfab.com/3d-models/coffee-cup-e9cb27d20c6b4ec3b675c39ef554d6d0
- **Free Coffee Mug Resource Pack** by PamJJ — visual reference for the tavern-style mug concept: https://www.planetminecraft.com/texture-pack/free-coffee-mug-resource-pack-teaser-for-the-upcoming-tavern-pack/

No third-party model file or texture from those pages is bundled in this repository. The item models and textures in this commit were created specifically for CoffeMinecraft.
