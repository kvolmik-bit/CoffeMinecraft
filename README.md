# Coffee Glass

Minecraft Forge 1.20.1 / Forge 47.4.10. This mod adds exactly one decorative item: a **large beer-mug-sized glass of coffee**, with a clear glass body, dark espresso, crema and a transparent side handle.

Version 1.0.2 enlarges the actual 3D geometry to nearly the full item-model bounds and increases its display scales in first-person, third-person, GUI and world item views. The model keeps separate walls, rim, base and handle geometry, with the existing transparent material and non-overlapping surfaces.

No crafting recipe, item-use action, effects, blocks or other gameplay mechanics.

Build with Java 17 using `gradle --no-daemon build`, or download the artifact from GitHub Actions.
