# Coffee Glass

A tiny Minecraft Forge 1.20.1 mod that adds exactly one decorative 3D item: coffee in a transparent glass. Its item model is custom 3D geometry with custom glass, coffee and crema textures, and tuned first-/third-person/world display transforms.

No crafting recipe. No right-click use. No effects. No other content.

Build with Java 17 using `gradle --no-daemon build`, or download the artifact from GitHub Actions.
