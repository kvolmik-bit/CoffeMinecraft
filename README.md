# Coffee Glass

Minecraft Forge 1.20.1 / Forge 47.4.10. This mod adds exactly one decorative item: the large mug modeled in `coffi_colored.bbmodel`.

Version 1.0.6 uses the supplied model's actual 9 elements, all 54 face UVs, exact display transforms, and five embedded PNG textures: glass base, glass highlights, reflections, espresso, and crema/latte art. The model uses Forge's translucent render type and no vanilla Minecraft textures.

No crafting recipe, item-use action, effects, blocks or other gameplay mechanics.

Build with Java 17 using `gradle --no-daemon build`, or download the artifact from GitHub Actions.
