# Coffee Glass

Minecraft Forge 1.20.1 / Forge 47.4.10. This mod adds exactly one decorative item: the large transparent coffee mug modeled in the supplied `coffi_colored.bbmodel`.

The in-game item model uses the model's actual 9 cuboids, UVs, hand/world display transforms, and all five embedded custom textures: clear glass, glass highlights, reflections, espresso, and crema/latte art. It uses Forge's translucent item render type and does not reference vanilla Minecraft textures.

No crafting recipe, item-use action, effects, blocks, or extra gameplay mechanics.

Build with Java 17 using `gradle --no-daemon build`, or download the artifact from GitHub Actions.
