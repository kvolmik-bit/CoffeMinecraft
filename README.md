# Coffee Mug

Minecraft Forge 1.20.1 / Forge 47.4.10. The mod contains one decorative item: `coffee_mug`.

The model JSON and PNG texture are taken from the supplied `coffee_mug_forge_1.20.1.zip` without editing their contents. The build restores the original model file byte-for-byte and keeps its original texture reference namespace.

No crafting recipe, item-use action, effects, blocks, extra items, or gameplay mechanics.

Build with Java 17 using `gradle --no-daemon build`, or download the JAR from GitHub Actions.
